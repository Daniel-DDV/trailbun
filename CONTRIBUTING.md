# Contributing

Contributions must be in English and should strengthen a specific claim.

## Preferred contribution

1. Identify one `ASSERTED` claim.
2. Add a deterministic mechanism or reproducible measurement.
3. Add tests for executable behavior.
4. Attach a completed Receipt Card.
5. Document scope, host and version assumptions, bypass paths, and failure modes.

Do not broaden claims beyond the supplied evidence. A smaller honest claim is preferable to a universal claim supported by one successful run.
